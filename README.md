# سرجمع (Sarejam)

اپ اندروید آفلاین برای مدیریت مالی، کاری و شخصی؛ پیامک و نوتیفیکیشن بانک‌ها را خودش می‌خواند و فقط وقتی لازم است سؤال می‌پرسد.

- سایت: [sarejam.ir](https://sarejam.ir)
- همه داده‌ها فقط روی گوشی کاربر می‌مانند.

## ساختار

| ماژول | وضعیت |
| --- | --- |
| `engine/parser` | ✅ موتور خواندن پیامک بانکی (Kotlin خالص) + تست |
| `docs/` | سندهای مرجع: محصول، معماری، موتور پیامک، طراحی، نقشه راه |
| `brand/` | لوگو، آیکون، فونت، رنگ‌ها، تصاویر سایت |
| `app`، `core/*`، `feature/*` | ⏳ نسخه ۰ |

## اجرای تست‌ها

```bash
gradle :engine:parser:test
```

## قوانین مخزن

- هیچ پیامک واقعی، شماره حساب، شماره کارت، رمز یا کلید امضا وارد مخزن نمی‌شود.
- نمونه‌های تست (`Fixtures.kt`) با اسم و عدد ساختگی نوشته می‌شوند؛ فقط ساختار پیام واقعی است.
