# سرجمع (Sarejam)

اپ اندروید آفلاین برای مدیریت مالی، کاری و شخصی؛ نسخهٔ اول فقط مالی است.

- سایت: [sarejam.ir](https://sarejam.ir)
- همهٔ داده‌ها روی گوشی کاربر می‌مانند.
- مرحلهٔ فعلی: پایهٔ اندروید با سیستم طراحی و پایگاه دادهٔ رمزدار. هنوز مدیریت حساب یا خواندن پیامک به رابط اپ متصل نشده است.

## ساختار

| ماژول | وضعیت |
| --- | --- |
| `app` | نقطهٔ شروع اندروید، Hilt و صفحهٔ آغاز Compose |
| `core:ui` | وزیرمتن محلی، تم‌های روشن/تیره/مشکی، رنگ‌ها و اجزای مشترک؛ نمونهٔ تعاملی در debug |
| `core:database` | Room + SQLCipher، کلید محافظت‌شده در Keystore، چهار جدول و آزمون‌های فایل واقعی |
| `engine:parser` | موتور خواندن پیامک بانکی، Kotlin خالص + تست |
| `core:model`، `core:common`، `engine:insight` | پایهٔ Kotlin خالص، آمادهٔ مراحل بعد |
| `capture`، `data:backup`، `feature:*` | ماژول‌های خالی با وابستگی‌های معماری؛ قابلیت‌ها طبق نقشهٔ راه اضافه می‌شوند |
| `docs/` | سندهای محصول، معماری، موتور پیامک، طراحی و نقشهٔ راه |
| `brand/` | لوگو، آیکون، فونت، رنگ‌ها و تصاویر سایت |

## ساخت و اجرا

۱. پروژه را در Android Studio با پشتیبانی AGP 9.5 باز کنید.
۲. از SDK Manager، **Android SDK Platform 37** و **Build-Tools 36.0.0** را نصب کنید. JDK 17 یا جدیدتر لازم است (ساخت این مرحله با JDK 21 بررسی شده است).
۳. صبر کنید همگام‌سازی Gradle تمام شود؛ مسیر SDK را Android Studio در `local.properties` می‌نویسد. این فایل محلی است و وارد مخزن نمی‌شود.
۴. یک شبیه‌ساز یا گوشی با اندروید ۸ به بالا انتخاب کنید و Run را بزنید.

از خط فرمان، در پوشهٔ پروژه:

```bash
./gradlew assembleDebug
./gradlew build test
```

در ویندوز به‌جای `./gradlew` از `gradlew.bat` استفاده کنید. بار اول دانلود ابزارها اینترنت می‌خواهد؛ خود اپ آفلاین است.

فایل نصبی آزمایشی در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود. این نسخه برای بررسی است؛ امضای انتشار و GitHub Releases در مرحلهٔ ۰.۷ اضافه می‌شوند.

فقط تست‌های موتور پیامک:

```bash
./gradlew :engine:parser:test
```

## آزمون پایگاه داده

با شبیه‌ساز یا دستگاه آزمایشی متصل:

```bash
./gradlew :core:database:connectedDebugAndroidTest
```

۱۷ آزمون در بستهٔ تست جدا، رمزنگاری فایل، بازنشدن با کلید غلط، حفظ کلید، خطاهای نوشتن و قیدهای جدول‌ها را بررسی می‌کنند. طرح نسخهٔ ۱ در `core/database/schemas/` ذخیره شده است؛ برای هر تغییر بعدی، Migration و تست آن لازم است.

## فونت و حریم خصوصی

فونت وزیرمتن داخل `core/ui/src/main/res/font/` از ادغام زیرمجموعه‌های فارسی و لاتین فایل‌های موجود در `brand/fonts/` و تبدیل WOFF2 به TTF ساخته شده است؛ مجوز OFL در `core/ui/src/main/assets/fonts/OFL-LICENSE.txt` همراه اپ بسته‌بندی می‌شود.

برای بازسازی فونت، ابزار `tools/convert_vazirmatn.py` را با پیش‌نیاز `fonttools[woff]` اجرا کنید؛ این ابزار فقط برای توسعه است و جزو اپ نیست.

این پایه هیچ مجوز پیامک یا اینترنت درخواست نمی‌کند و بکاپ خودکار سیستم خاموش است؛ بکاپ انتخابی رمزدار در مرحلهٔ خودش ساخته می‌شود.

## قوانین مخزن

- راهنمای کار: `CLAUDE.md` و `docs/ROADMAP.md`.
- هیچ پیامک واقعی، شماره حساب، شماره کارت، رمز یا کلید امضا وارد مخزن نمی‌شود.
- نمونه‌های تست (`Fixtures.kt`) با اسم و عدد ساختگی نوشته می‌شوند؛ فقط ساختار پیام واقعی است.
