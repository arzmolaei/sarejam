# سیستم طراحی سرجمع

همهٔ اجزای این ماژول آفلاین‌اند، فونت وزیرمتن را از فایل محلی می‌خوانند و در `SarejamTheme` راست‌به‌چپ هستند. ورودی صفحهٔ نمونه فقط در نسخهٔ آزمایشی اپ (`BuildConfig.DEBUG`) دیده می‌شود؛ این صفحه گردش محصول نیست.

```kotlin
SarejamTheme(themeMode = ThemeMode.AMOLED, accentColor = AccentColor.LAPIS) {
    SarejamCard {
        MoneyText(amountRial = -320_000L)
    }
}
```

فراخوانی قبلی `SarejamTheme { … }` معتبر است و پیش‌فرض از تم گوشی پیروی می‌کند. `ThemeMode` حالت‌های گوشی، روشن، تیره، مشکی مطلق، غروب واقعی و ساعت ثابت دارد؛ `AccentColor` فیروزه، لاجورد، زعفران، انار، یاس و رنگ والپیپر. رنگ والپیپر در API 31 به بالا پویاست؛ پایین‌تر فیروزه است.

حالت `SUNSET` طلوع و غروب را برای **شهر مرجع تهران** با محاسبهٔ نجومی تقریبی تعیین می‌کند؛ مکان گوشی خوانده نمی‌شود. برای شهر دیگر، برنامه‌نویس `solarLocation` و `solarTimeZone` هماهنگ را به تم می‌دهد. منطقهٔ زمانی پیش‌فرض `Asia/Tehran` است و جابه‌جایی ساعت گوشی به کشور دیگر شهر مرجع را عوض نمی‌کند. این محاسبه برای رنگ رابط مناسب است؛ مبنای اوقات شرعی نیست. صفحهٔ نمونه نام تهران را آشکارا نشان می‌دهد. انتخاب شهر در تنظیمات، جزو این مرحله نیست.

حالت اختیاری `AUTO_TIME` از ساعت **محلی گوشی** استفاده می‌کند: از ۱۸ تا پیش از ۶ تیره است؛ این گزینه «غروب» نامیده نمی‌شود. هر دو حالت فقط هنگام باز بودن صفحه به اعلان تغییر دقیقه، ساعت و منطقهٔ زمانی اندروید گوش می‌دهند؛ در پس‌زمینه گیرنده ثبت‌شده، تایمر، خدمت یا کار زمان‌بندی‌شده ندارند.

`SarejamTheme.colors` رنگ‌های واریز، برداشت، هدف، متن روی هدف و متن کم‌رنگ را در دسترس بقیهٔ ماژول‌ها می‌گذارد. بقیهٔ رنگ‌ها، قلم‌ها و گوشه‌ها از `MaterialTheme` می‌آیند. همهٔ ۱۵ نقش تایپوگرافی فونت محلی دارند؛ وزن‌های ۴۰۰، ۵۰۰، ۷۰۰ و ۸۰۰ واقعاً بسته‌بندی می‌شوند. مبلغ بزرگ ۳۲/۸۰۰، عنوان صفحه ۲۲/۷۰۰، عنوان کارت ۱۶/۷۰۰، متن ۱۴/۴۰۰ و توضیح ۱۲/۴۰۰ هستند.

`MoneyText` مبلغ صحیح ریال (`Long`) می‌گیرد؛ هیچ تبدیل اعشاری ندارد و حتی کمینه و بیشینهٔ `Long` را دقیق نشان می‌دهد. علامت مثبت/منفی در کنار رنگ، رقم فارسی یا انگلیسی، جداساز هزارگان، رقم هم‌عرض (`tnum`) و خواندن یکپارچه برای TalkBack دارد. اندازهٔ پیش‌فرض ۳۲ است و متن بدون حذف عدد می‌تواند چندخطی شود؛ برای فهرست از نقش کوچک‌تر تایپوگرافی استفاده شود.

`SarejamCard` بدون سایه و با گوشهٔ ۱۶ و فاصلهٔ ۱۶/۸ است. `EmptyState` یک جمله و یک دکمه می‌گیرد؛ متن‌های فراخواننده باید از منبع XML باشند. صفحهٔ نمونه انتخاب زندهٔ حالت و رنگ، مبلغ‌های ساختگی، همهٔ اجزای مشترک، دکمهٔ فعال/غیرفعال و نمونهٔ وزن‌های قلم را دارد.

بازسازی فونت‌ها: `python tools/convert_vazirmatn.py` با `fonttools[woff]`. فایل‌های وب و مجوز OFL در مخزن‌اند؛ زمان‌های منبع حفظ می‌شوند تا خروجی تکرارپذیر باشد.
