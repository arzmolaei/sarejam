# برنامهٔ اجرای پایهٔ اندروید — مرحلهٔ ۰.۲

هدف: APK با شناسهٔ `ir.sarejam.app`، حداقل اندروید ۸ و صفحهٔ «سرجمع» با فونت محلی وزیرمتن.
مرجع الزام‌آور: `CLAUDE.md`، `docs/ARCHITECTURE.md` و مرحلهٔ ۰.۲ در `docs/ROADMAP.md`.

## تصمیم‌ها

- ساختار چندماژولی سند معماری؛ ماژول‌های آینده فعلاً خالی، بدون قابلیت کاری/شخصی.
- Gradle Wrapper با checksum، Version Catalog، Kotlin و Compose و Hilt.
- compile/target SDK برابر ۳۷ (آخرین API پایدار موجود در فهرست رسمی)، minSdk برابر ۲۶؛ JVM برابر ۱۷.
- Kotlin خالص برای model/common/parser/insight؛ وابستگی‌های اندروید فقط در ماژول‌های اندرویدی.
- صفحهٔ آغاز ساده با RTL، متن منبع فارسی، فونت وزیرمتن محلی؛ سیستم تم کامل و آیکون در مراحل ۰.۳ و ۰.۴.
- بدون اجازهٔ پیامک یا اینترنت و بدون بکاپ سیستم؛ دادهٔ مالی هنوز ساخته نمی‌شود.

## اجرا و بررسی

- [x] ابزارهای ساخت محلی و Wrapper؛ ثبت نسخه‌ها و راهنمای اجرای تکرارپذیر.
- [x] تعریف ماژول‌ها و وابستگی‌های مطابق معماری و حفظ تست‌های parser.
- [x] Application و Activity با Hilt و Compose؛ متن و فونت محلی با مجوز OFL.
- [x] `./gradlew assembleDebug build test`؛ بررسی manifest خروجی و تست‌های موتور.
- [x] نصب روی شبیه‌ساز، بازشدن Activity، بررسی متن فارسی و RTL و نبود crash.
- [x] بازبینی تغییرات، ثبت نتیجهٔ واقعی در README/ROADMAP، ثبت تغییرات در شاخهٔ جدا و آماده‌سازی درخواست ادغام.

## موارد بازبینی

شناسهٔ اپ ثابت؛ مستقل‌ماندن parser؛ نبود مجوز غیرضروری و دادهٔ خصوصی؛ فونت قابل‌خواندن اندروید (TTF به‌جای WOFF2)؛ عدم تیک مرحله در صورت ناتمام بودن اجرای شبیه‌ساز.

## نتیجهٔ بررسی

- `./gradlew assembleDebug build test`: موفق (۸۷۰ کار Gradle؛ تست‌های موتور ۲۵/۲۵).
- `adb install --no-streaming -r ...`: موفق؛ `am start -W -n ir.sarejam.app/.MainActivity`: وضعیت ok.
- متن «سرجمع» در درخت رابط و تصویر شبیه‌ساز API 26 تأیید شد؛ خطای AndroidRuntime برای اپ گزارش نشد.
- بازبینی مستقل: حفظ `samples-private/` و حذف همهٔ دامنه‌های بکاپ سیستم اصلاح شد؛ ابزار بازسازی فونت هم اضافه شد.
- موتور پیامک هیچ تغییر کد یا تستی ندارد؛ فقط پیکربندی ساخت و وابستگی آزمون برای Gradle جدید به‌روز شد.
- برای اجرا در این محیط، JDK/SDK و تنظیمات پراکسی فقط در مسیرهای محلی نگه داشته شد؛ هیچ مسیر محلی یا تنظیم احراز هویت وارد کد نشده است.
