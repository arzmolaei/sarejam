# نقشه راه سرجمع

هر کار یک تیک دارد. Claude Code کارها را به ترتیب انجام می‌دهد و بعد از هر کار تیکش را می‌زند. «تمام شد» یعنی معیار آن کار واقعاً بررسی شده است.

  بررسی ۱۴۰۵/۰۸/۱۵: `./gradlew assembleDebug build test` موفق، ۲۵ تست بدون خطا؛ نصب و نمایش عنوان روی شبیه‌ساز اندروید ۸ (API 26) تأیید شد.

  تمام شد: آیکون روی صفحه اصلی شبیه‌ساز درست است، با و بدون «آیکون‌های رنگی».

## نسخه ۱ — مالی هوشمند (اولین نسخه برای دوستان)

نسخه ۱ **فقط مالی** است؛ هیچ کار بخش کاری/شخصی پیش از `v1.0.0` ساخته نمی‌شود.

  تمام شد: تست نشان دهد تجزیه دوباره فیلد دستی‌شده را عوض نمی‌کند و `TRANSFER`/`ADJUSTMENT` در گزارش خرج نمی‌آیند.
- [ ] **1.1 شروع کار** — طبق `docs/PRODUCT.md`: فقط اجازه پیامک، راهنمای هر محیط نصب (جدول `docs/ARCHITECTURE.md`)؛ نوتیفیکیشن بعداً.
- [ ] **1.2 گرفتن پیامک زنده** — `SmsReceiver` → parser → ذخیره؛ رعایت قانون‌های Otp و NotBank.
  تمام شد: پیامک آزمایشی (`adb emu sms send`) در کمتر از ۱ ثانیه تراکنش می‌شود؛ پیامک شخصی هیچ ردی در دیتابیس نمی‌گذارد.
- [ ] **1.3 وارد کردن ۶ ماه گذشته** — اسکن صندوق با WorkManager و نوار پیشرفت.
- [ ] **1.4 حساب‌ها** — ساخت خودکار، اسم‌گذاری، ادغام، بایگانی، فضا (شخصی/کاری)، کیف نقدی، همه حالت‌های `docs/PRODUCT.md`.
- [ ] **1.5 ربط‌دهنده‌ها و کنترل مانده** — `Linker` با سه وضعیت + هشدار «یک تراکنش جا افتاده» + ردیف `ADJUSTMENT` (نه خرج).
- [ ] **1.6 دسته‌بندی** — دسته‌های پیش‌فرض فارسی، قانون از تأیید کاربر (`engine:insight`)، دفترچه کارت‌ها، نوتیفیکیشن ۳دکمه‌ای.
  تمام شد: بعد از ۲ تأیید برای یک کارت مقصد، سومی خودکار دسته می‌گیرد.
