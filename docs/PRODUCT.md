# محصول سرجمع

سرجمع یک اپ اندروید آفلاین است که خودش از پیامک و نوتیفیکیشن بانک‌ها می‌فهمد پول کجا رفت، فقط وقتی لازم است سؤال می‌پرسد، و کارها و زندگی روزمره را هم کنار پول مدیریت می‌کند. اول برای سازنده و دوستانش، با کیفیت قابل انتشار عمومی.

## سه بخش، یک صفحه «امروز»

| بخش | چه می‌کند |
| --- | --- |
| مالی (قلب اپ) | ثبت خودکار از پیامک و نوتیفیکیشن، دسته‌بندی هوشمند، حساب‌ها، انتقال داخلی و کارمزد، بودجه، اقساط و وام و چک، قرض و دنگ، گزارش و پیش‌بینی |
| کاری | کارها و پروژه‌ها، یادآور، سررسید، درآمد هر پروژه، فضای «کاری» جدا برای حساب‌ها |
| شخصی | عادت‌ها، هدف‌ها، یادداشت، خلاصه روزانه |

## اصول

1. کمترین تایپ: هر چیزی که خودکار فهمیده می‌شود، پرسیده نمی‌شود.
2. سؤال در لحظه: دسته‌بندی از داخل خود نوتیفیکیشن با ۳ دکمه پیشنهادی.
3. داده مال کاربر است: بدون سرور، بدون حساب کاربری؛ «هیچ داده‌ای بدون انتخاب صریح شما از گوشی خارج نمی‌شود».
4. هیچ آپدیتی داده را خراب نمی‌کند؛ همیشه بکاپ قابل بازگردانی هست.
5. هر نسخه به‌تنهایی کامل و قابل استفاده است.
6. هیچ چیز نیمه‌کاره منتشر نمی‌شود: یا کامل کار می‌کند یا هنوز در اپ نیست.
7. **هسته اول:** سرجمع «اپی است که خودش حساب‌وکتابت را انجام می‌دهد». کار و زندگی بعد از ضدگلوله شدن موتور مالی به آن وصل می‌شوند (پروژه با واریز مشتری «پرداخت‌شده» شود، کار قسط با پیامک پرداخت تیک بخورد، هدف پس‌انداز خودکار جلو برود).
8. **شفافیت:** هر تشخیص خودکار دلیلش را نشان می‌دهد و یک دکمه «اشتباه بود» دارد.

## سه قابلیت شاخص

1. **«تا حقوق بعدی»** — کارت اول صفحه امروز: «۱۷ روز تا حقوق؛ با قبض‌ها و اقساط پیش رو، روزی حدود ۴۲۰ هزار تومان می‌توانی خرج کنی». نسخه ۱: از روز حقوق و میانگین خرج؛ نسخه ۲: با قسط، چک و خرج‌های تکراری.
2. **«چرا؟»** — زیر هر دسته خودکار: «غذا — اطمینان ۹۲٪؛ چون ۳ خرید قبلی به این کارت را غذا ثبت کردی» + «اشتباه بود» که قانون را اصلاح می‌کند.
3. **صندوق اصلاحات** — به‌جای لیست بلند بی‌دسته‌ها: «این هفته ۳۴ تراکنش را خودم فهمیدم؛ ۲ مورد مشکوک است». کاربر فقط همان‌ها را می‌بیند. صفحه «سلامت خواندن» (ملت — ۲۳۴ خوانده — ۲۳۱ قطعی — ۳ بررسی — آخرین تطبیق مانده درست) جواب سؤال «می‌توانم به عددها اعتماد کنم؟» است و از صفحه امروز یک لمس فاصله دارد.

## حساب‌ها: همه حالت‌ها

کاربر هیچ حسابی را دستی تعریف نمی‌کند؛ هر حساب با اولین پیامکش ساخته می‌شود و فقط یک اسم کوتاه پرسیده می‌شود. اگر فقط یک حساب باشد، انتخاب حساب از همه فرم‌ها حذف می‌شود.

| حالت | رفتار |
| --- | --- |
| چند حساب در چند بانک | هر حساب جدا با مانده خودش + جمع کل |
| چند حساب در یک بانک | جداسازی با شماره حساب/کارت داخل پیامک |
| بانکی بدون شماره حساب در پیامک (بلو) | جداسازی با فرستنده؛ دو حساب → با پیوستگی مانده |
| یک حساب با چند شکل شماره | پیشنهاد ادغام «این دو یکی‌اند؟» |
| دو سیم‌کارت | پیامک هر دو سیم خوانده می‌شود؛ شناسه سیم (`subscriptionId`) بخشی از هویت منبع است، پس دو حساب یک بانک روی دو سیم قاطی نمی‌شوند |
| حساب بدون پیامک | نوتیفیکیشن اپ بانک، یا ثبت دستی + یادآور «مانده را چک کن» |
| پول نقد | کیف نقدی؛ برداشت از عابربانک = انتقال به کیف نقدی |
| خرید اعتباری (اسنپ‌پی، دیجی‌پی، کالابرگ…) | حساب اعتباری با سقف و بدهی، اقساط خودکار |
| شخصی و کاری | هر حساب یک «فضا» دارد؛ گزارش جدا یا با هم |
| پس‌انداز / سپرده | قابل حذف از «پول قابل خرج»، در دارایی کل |
| حساب مشترک خانوادگی | برچسب «مشترک»؛ بعداً حالت خانوادگی |
| حساب ارزی | واحد پول جدا برای هر حساب |
| حساب بسته‌شده | بایگانی؛ تاریخچه می‌ماند |
| کیف پول اپ‌ها | کیف الکترونیکی؛ شارژ آن = انتقال، نه خرج |

اصلاح دستی مانده، یا اختلافی که کنترل مانده پیدا می‌کند = یک ردیف از نوع **«تطبیق مانده»** (`ADJUSTMENT`)، نه خرج یا درآمد؛ در گزارش خرج و درآمد حساب نمی‌شود تا کاربر علتش را مشخص کند.

## صفحه‌ها و ناوبری

نوار پایین پنج بخش + دکمه شناور «+» (ثبت سریع هزینه، کار یا یادداشت).

| بخش | محتوا |
| --- | --- |
| امروز | خرج امروز و این ماه، بی‌دسته‌ها، کارهای امروز، پرداخت‌های نزدیک، عادت‌های امروز |
| تراکنش‌ها | لیست با جستجو و فیلتر، مرور سریع بی‌دسته‌ها، حساب‌ها و مانده‌ها |
| کارها | امروز / بعداً / پروژه‌ها، لیست خرید، عادت‌ها |
| گزارش | هزینه به تفکیک دسته، مقایسه ماه‌ها، بودجه، پیش‌بینی، هشدارها، دارایی کل |
| بیشتر | وام و قسط، چک، قرض و دنگ، هدف‌ها، یادداشت‌ها، دسته‌ها و قانون‌ها، بکاپ، تنظیمات، سلامت خواندن |

بیرون از اپ: نوتیفیکیشن «این پول برای چی بود؟»، ویجت (خرج امروز + ثبت سریع)، کاشی نوار بالای گوشی، «اشتراک‌گذاری به سرجمع» برای عکس رسید.

شروع کار: خوش‌آمد ← توضیح حریم خصوصی ← **فقط اجازه پیامک** (با راهنمای تصویری «تنظیمات محدودشده» اگر اندروید ۱۵+ و نصب خارج از استور) ← خواندن پیامک‌های ۶ ماه گذشته ← اولین گزارش «پولت این‌جاها رفته». **اول اعتماد، بعد اجازه دوم:** دسترسی نوتیفیکیشن بعداً و فقط وقتی پیشنهاد می‌شود که بانکی پیامک کامل نفرستد یا کاربر اپ پرداختی مثل اسنپ‌پی داشته باشد.

## همه‌چیز اختیاری

فقط خواندن پیامک و بکاپ خودکار از اول روشن‌اند (هسته کار). بقیه:

| تنظیم | پیش‌فرض |
| --- | --- |
| قفل اپ (اثر انگشت / رمز) و زمان قفل خودکار | خاموش |
| سؤال «این پول برای چی بود؟» | روشن، بی‌صدا؛ قابل تغییر به باصدا، فقط بالای مبلغ X، یا خاموش |
| ثبت خودکار دسته وقتی اپ مطمئن است | روشن |
| یادآور مرور شبانه بی‌دسته‌ها | خاموش |
| گزارش هفتگی جمعه‌شب | خاموش |
| هشدار بودجه و خرج غیرعادی | فقط اگر بودجه تعریف شود |
| یادآور سررسید قسط و چک | فقط اگر قسط یا چک ثبت شود |
| حالت مخفی مبلغ‌ها | خاموش |
| جلوگیری از اسکرین‌شات | خاموش |
| لرزش و صدای لمس | لرزش سبک روشن، صدا خاموش |
| بخش‌های کاری و شخصی | روشن؛ هر کدام قابل پنهان کردن |
| اینترنت (آپدیت، قیمت‌ها، الگوی بانک) | هر کدام جدا، قابل خاموش کردن |

پیشنهادهایی مثل قفل بعداً یک بار و بی‌اصرار نشان داده می‌شوند.

## ایده‌های بعدی (در ROADMAP زمان‌بندی شده)

ثبت صوتی، عکس رسید، دارایی کل با قیمت طلا/ارز، نمای تورم، دستیار پرسش‌وپاسخ آفلاین، الگوی گروهی بانک‌ها (فقط ساختار پیامک، با اجازه کاربر)، حالت خانوادگی با همگام‌سازی رمزنگاری‌شده سرتاسری.
