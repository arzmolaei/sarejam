# سرجمع ۰.۱.۰ — نسخه پایه

نسخه آزمایشی برای دیدن پایه اپ؛ هنوز پیامکی خوانده نمی‌شود.

- نمونه سیستم طراحی: روشن، تیره، مشکی مطلق و شش رنگ اصلی، راست‌به‌چپ با فونت وزیرمتن
- آیکون اپ (با پشتیبانی آیکون تک‌رنگ اندروید ۱۳ به بعد) و صفحه شروع
- دیتابیس رمزدار روی گوشی (هنوز خالی)
- قفل اختیاری با رمز و اثر انگشت (پیش‌فرض خاموش)
